# תזרים: תחזית תזרים מזומנים אישי

אפליקציית ווב (PWA) לטלפון, בעברית: תחזית יתרת העו"ש ל-12 חודשים קדימה, לפי יתרה נוכחית, משכורת, הוצאות קבועות, הוצאות משתנות ופריטים חד-פעמיים.

- **פרטיות:** הנתונים נשמרים רק במכשיר (localStorage). האפליקציה לא שולחת שום מידע החוצה, ומדיניות האבטחה בדף (CSP) חוסמת כל תקשורת לשרת אחר.
- **בלי אינטרנט:** אחרי הפתיחה הראשונה היא עובדת גם בלי רשת.
- **בלי ספריות ובלי build:** HTML, CSS ו-JavaScript רגילים.

## מבנה הקבצים

```
index.html              מעטפת האפליקציה
styles.css              עיצוב (RTL, כהה/בהיר אוטומטי)
js/calc.js              לוגיקת החישוב
js/storage.js           שמירה במכשיר, ייצוא וייבוא
js/app.js               מסכים וטפסים
sw.js                   service worker (עבודה בלי אינטרנט)
manifest.webmanifest    התקנה למסך הבית
icons/                  אייקונים
tests/                  בדיקות ללוגיקת החישוב
```

## הפעלה מקומית במחשב

צריך שרת מקומי, כי service worker לא עובד בפתיחה ישירה של הקובץ. אחת מהאפשרויות:

```bash
# אם מותקן Python
python -m http.server 8000

# או אם מותקן Node.js
npx serve .
```

אחר כך פותחים בדפדפן את `http://localhost:8000`.

**בדיקות:** פותחים את `http://localhost:8000/tests/` (או ישירות את הקובץ `tests/index.html`) ורואים את תוצאות הבדיקות. עם Node.js אפשר גם להריץ `node tests/calc.test.js`.

## העלאה לאינטרנט בחינם

האפליקציה חייבת לרוץ ב-HTTPS כדי שאפשר יהיה להתקין אותה בטלפון. שתי האפשרויות הבאות נותנות HTTPS בחינם.
הקבצים שמועלים הם רק קוד האפליקציה. **הנתונים האישיים שלכם לא עולים לשום מקום**, הם נשמרים רק בטלפון.

### אפשרות א': GitHub Pages

1. נכנסים ל-[github.com](https://github.com), ופותחים חשבון אם עוד אין.
2. **New repository**, נותנים שם (למשל `tazrim`), בוחרים **Public** ולוחצים **Create repository**.
3. בדף ה-repository: **uploading an existing file**. גוררים לשם את **כל התוכן** של התיקייה (כולל התיקיות `js`, `icons` ו-`tests`) ולוחצים **Commit changes**.
4. **Settings** ← **Pages**. תחת **Source** בוחרים **Deploy from a branch**, ענף `main`, תיקייה `/ (root)`, ולוחצים **Save**.
5. אחרי דקה-שתיים האתר זמין בכתובת `https://<שם-המשתמש>.github.io/tazrim/`.

> ב-GitHub Pages חינמי ה-repository חייב להיות ציבורי. הקוד גלוי לכולם, אבל אין בו שום נתון אישי.

### אפשרות ב': Netlify (הכי פשוט, בלי חשבון GitHub)

1. נכנסים ל-[app.netlify.com/drop](https://app.netlify.com/drop) ונרשמים בחינם.
2. גוררים את **כל התיקייה** לחלון.
3. מקבלים כתובת בסגנון `https://something.netlify.app`. אפשר לשנות אותה ב-**Site configuration** ← **Change site name**.

### עדכון גרסה

אחרי שינוי בקבצים, מעלים את מספר הגרסה בשורה `const CACHE = 'tazrim-v1'` בקובץ `sw.js` (למשל ל-`tazrim-v2`) ומעלים מחדש. הטלפון מוריד את העדכון ברקע, והגרסה החדשה מופיעה **בפתיחה שאחרי**. אם צריך אותה מיד, סוגרים את האפליקציה ופותחים שוב.

## התקנה למסך הבית

### אייפון (Safari)
1. פותחים את כתובת האתר ב-**Safari**. בדפדפנים אחרים באייפון זה לא תמיד אפשרי.
2. לוחצים על כפתור השיתוף (ריבוע עם חץ למעלה).
3. **הוספה למסך הבית**, ואז **הוסף**.

### אנדרואיד (Chrome)
1. פותחים את כתובת האתר ב-**Chrome**.
2. תפריט ⋮, ואז **התקנת אפליקציה** (או **הוספה למסך הבית**).
3. מאשרים.

מעכשיו האפליקציה נפתחת מהאייקון במסך מלא, וגם בלי אינטרנט.

> **חשוב באייפון:** האפליקציה שהותקנה למסך הבית שומרת נתונים נפרדים מהאתר שנפתח ב-Safari. מזינים את הנתונים באפליקציה המותקנת.

## גיבוי והעברה בין מכשירים

הנתונים נשמרים רק במכשיר. מחיקת נתוני הדפדפן או הסרת האפליקציה ימחקו אותם.

- **ייצוא:** מסך **גיבוי**, ואז **ייצוא לקובץ**. נשמר קובץ `tazrim-backup-<תאריך>.json`. מומלץ לשמור אותו ב-iCloud או ב-Google Drive, או לשלוח אותו לעצמכם.
- **ייבוא:** במכשיר החדש: מסך **גיבוי**, ואז **בחירת קובץ…**. הייבוא **מחליף** את כל הנתונים במכשיר, ומופיעה בקשת אישור לפני כן.

## איך החישוב עובד

- התחזית מתחילה מהיתרה שהוזנה ומתקדמת חודש אחר חודש: **יתרה קודמת + משכורת + הכנסות חד-פעמיות − קבועות פעילות − משתנות − הוצאות חד-פעמיות**.
- **החודש של עדכון היתרה:** משכורת והוצאות קבועות שהיום שלהן **עד** יום העדכון (כולל) נחשבות כאילו כבר נכללו ביתרה, ולא נספרות שוב. המשתנות של אותו חודש נספרות תמיד, כי הן יורדות בסוף החודש.
- **משתנות:** לכל חודש נלקח סכום בפועל אם הוזן, אחרת הערכה מיוחדת לחודש, אחרת ברירת המחדל.
- **קבועות:** נספרות מחודש ההתחלה ועד חודש הסיום (כולל). הוצאה מושהית לא נספרת בכלל עד שמחדשים אותה. יום 31 בחודש קצר עובר ליום האחרון של החודש.
- **משכורת:** בכל חודש נלקח הסכום האחרון שתחילתו לא אחרי אותו חודש, כך שהעלאה ממרץ חלה ממרץ והלאה.
- **הנקודה הנמוכה:** התנועות בכל חודש ממוינות לפי יום, כדי לזהות ירידה זמנית, למשל כששכר הדירה יורד לפני שהמשכורת נכנסת. כדי שההתראה תהיה זהירה, הוצאה חד-פעמית נחשבת בתחילת החודש, הכנסה חד-פעמית בסופו, וביום זהה הוצאות נספרות לפני הכנסות.
- **התראה אדומה:** מופיעה אם הנקודה הנמוכה בשנה הקרובה יורדת מתחת לסף המינימום (ברירת מחדל: 0).
- אם היתרה עודכנה לפני כמה חודשים, החודשים שעברו מאז מוצגים בטבלה באפור, ושם כדאי להזין את סכום המשתנות בפועל.
